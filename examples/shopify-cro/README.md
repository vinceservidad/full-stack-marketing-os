# Shopify CRO Audit — Worked Example

**Status:** Synthetic worked example

This example shows how `$cro` turns page/funnel evidence into a prioritized hypothesis set instead of producing a generic redesign checklist.

## Starting request

> Paid traffic is reaching the product page, but purchase rate is weak. Audit the Shopify funnel and tell me what to fix first.

## Business

Fictional brand: **Packwell**

Product: modular carry-on organizer set

Market: United States

All page facts, customer evidence, and metrics are synthetic.

## Owner chain

```text
$marketing-intake
→ $performance-diagnostics
→ $cro
→ $offer-strategy or $copywriting only where their decisions are actually needed
→ $tracking-measurement for experiment validity
```

`$cro` owns page/funnel friction and conversion hypotheses. It does not automatically own price setting, offer architecture, customer research, or paid-media acquisition quality.

Show how the OS identifies the smallest high-value conversion problem, preserves strong existing elements, and builds a measurable change instead of redesigning everything at once.
