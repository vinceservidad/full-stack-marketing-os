# DTC Creative Strategy — Worked Example

**Status:** Synthetic worked example

This example demonstrates the governed path from customer/product evidence to a paid-social static concept and test plan.

## Starting request

> Build new Meta static-ad concepts for this product. Use customer evidence, make the ideas strategically distinct, and make the 4:5 assets safe for a centered square crop.

## Business

Fictional brand: **CarryKind**

Product: structured everyday tote with removable internal organizers

Audience situation: commuters and parents who dislike digging through an unstructured bag.

All product facts, reviews, and performance data in this example are synthetic and clearly labeled for teaching purposes.

## Owner chain

```text
$marketing-intake
→ $customer-research
→ $icp-jtbd
→ $creative-strategy
→ $tracking-measurement for test validity
```

`$creative-strategy` owns the paid-ad angle, mechanic, concept, hook, visual format, production direction, and test cell. It does not invent product claims or treat reference patterns as proof.
