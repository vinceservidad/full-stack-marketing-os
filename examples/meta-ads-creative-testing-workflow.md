# Meta Ads Creative Testing Workflow Example

## Goal
Create a repeatable creative testing process.

## Process

1. Research
- Customer problems
- Desired outcomes
- Objections
- Existing customer language

2. Create angles
Examples:
- Problem aware
- Solution aware
- Social proof
- Product benefit
- Founder/story

3. Build test matrix
- Hook
- Visual concept
- Format
- Copy angle
- Audience context

4. Evaluate
Look beyond CTR alone:
- Cost per acquisition
- Conversion quality
- Revenue impact
- Creative fatigue

Public examples should explain the method, not reveal private client data.
