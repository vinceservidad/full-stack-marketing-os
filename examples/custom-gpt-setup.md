# Custom GPT Setup

## Knowledge Upload

Upload the curated files from `gpt-knowledge/`.

## Instruction Layer

The GPT should:

1. Identify the business objective.
2. Select the correct specialist skill.
3. Apply the relevant framework.
4. Use templates when creating deliverables.
5. Run a quality and humanization review before final output.

## Source of Truth

GitHub remains the versioned source. GPT knowledge files are the portable execution layer.
