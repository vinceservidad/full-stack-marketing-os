# Security Policy

## Reporting Issues

If you discover a security issue, please report it privately to the repository owner instead of opening a public issue.

## Scope

This repository contains marketing frameworks, skills, documentation, and AI workflow structures. Do not submit private client data, credentials, or confidential business information.

## Responsible Use

Contributors should avoid including:

- API keys or secrets
- Client account data
- Personal information
- Private campaign exports
- Confidential business documents
