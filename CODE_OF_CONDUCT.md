# Code of Conduct

## Our Commitment

We want this project to be a welcoming and constructive place for marketers, developers, researchers, and contributors.

## Expected Behavior

- Be respectful and professional.
- Provide constructive feedback.
- Focus discussions on improving the project.
- Respect different backgrounds and perspectives.

## Unacceptable Behavior

- Harassment or personal attacks.
- Discriminatory language.
- Publishing private information.
- Disruptive behavior that prevents collaboration.

## Reporting Issues

If you experience or see unacceptable behavior, open a private discussion with the maintainers through GitHub where possible.

Thank you for helping improve Full-Stack Marketing OS.
