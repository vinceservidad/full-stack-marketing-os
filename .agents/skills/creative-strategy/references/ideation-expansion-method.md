# Ideation Expansion Method

Use this method after a verified audience insight and initial strategic framing exist, when the goal is to generate enough distinct creative directions for a useful test plan without turning quantity into random variation.

Classify this as a methodology under [`KNOWLEDGE-TAXONOMY.md`](../../../../KNOWLEDGE-TAXONOMY.md). It expands hypotheses; it does not manufacture evidence or prove that any idea will perform.

## Expansion sequence

Start with one verified insight or clearly labeled hypothesis, then expand deliberately:

```text
1 verified insight
→ 3–5 evidence-compatible angles
→ 2–3 hooks per angle
→ 1–2 concepts per hook
→ suitable formats
→ proof treatment
→ CTA
→ controlled test cells
```

The counts are planning ranges, not quotas. Generate fewer when the evidence supports fewer meaningful directions.

## What changes at each layer

- **Angle:** Change the strategic reason to care.
- **Hook:** Change the opening expression while preserving the underlying angle.
- **Concept:** Change how the angle is dramatized, demonstrated, narrated, or visualized.
- **Format:** Change the delivery form only when it suits the concept and placement.
- **Proof:** Change the evidence treatment only when multiple substantiated forms exist.
- **Offer framing / CTA:** Change these only when the test question is specifically about the offer or next action.

Do not count cosmetic rewrites, crop adaptations, background changes, or synonym swaps as new strategic ideas.

## Expansion gates

Before expanding an idea, confirm:

1. The source insight is observed, supplied, or explicitly labeled as a hypothesis.
2. The angle is supported by product truth and does not require an invented claim.
3. The hook matches the audience's likely awareness and does not overstate proof.
4. The concept has a clear communication job beyond visual novelty.
5. The format is appropriate for the concept and destination.
6. The test cell can be interpreted because the major variable is identifiable.

If a gate fails, do not compensate by producing more variants.

## Diversity test

Two ideas are strategically distinct only if a reasonable reviewer can explain what different proposition, belief shift, motivation, objection, or mechanism each one is testing.

Ask:

- Would these ideas teach different things if one wins and the other loses?
- Is the reason to care different, or only the wording?
- Is the proof doing a different strategic job, or only appearing in a different layout?
- Does the audience need a different belief to accept each idea?

If the answer is no, consolidate them.

## Ranking

Prioritize cells using evidence fit, business relevance, differentiation, proof availability, production feasibility, and learning value. Do not rank an idea as likely to win simply because it sounds clever or follows a known framework.

## Handoff to testing

The expansion output becomes an input to [`workflows/creative-ideation-engine.md`](../../../..//workflows/creative-ideation-engine.md) and then [`workflows/creative-testing.md`](../../../..//workflows/creative-testing.md). Before launch, each selected cell needs a success signal, business guardrail, decision window, and controlled variable.

## Anti-patterns

Reject:

- idea quotas that force weak angles
- one insight rewritten 20 ways and labeled 20 concepts
- fabricated testimonials, statistics, urgency, scarcity, or competitor claims
- combining new angle + new hook + new format + new offer in one learning cell without a deliberate multivariate design
- treating generated ideas as customer evidence
- calling an untested angle a winner, best practice, or proven pattern

The purpose of expansion is not maximum output. It is maximum useful learning per production round.
