# Release Checklist

## v1.0.0

Before public release:

- [ ] README explains the purpose clearly
- [ ] No private client information included
- [ ] Frameworks are documented
- [ ] Skills have clear instructions
- [ ] Agents have routing rules
- [ ] Templates are reusable
- [ ] Evaluations cover common tasks
- [ ] Examples are anonymized
- [ ] License is included
- [ ] Contribution guidelines are updated

## Quality Standard

Every addition should answer:

1. What problem does this solve?
2. Which skill owns this?
3. Which framework supports it?
4. How is quality evaluated?
