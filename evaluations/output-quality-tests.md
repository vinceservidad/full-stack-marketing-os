# Output Quality Evaluations

## Purpose
Ensure generated outputs follow the operating system standards.

## Quality Checks

Every response should:

- Identify the business objective
- Use the correct framework
- Separate strategy from tactics
- State assumptions
- Avoid invented data
- Consider measurement
- Provide practical next steps

## Human Review

Before delivery check:

- Is it clear?
- Is it actionable?
- Is it commercially useful?
- Does it match the intended audience?
- Does it follow Vince writing style?
