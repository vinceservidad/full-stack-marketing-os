# Contributing to Full-Stack Marketing OS

Thank you for helping improve this project.

## Contribution principles

Contributions should improve the system, not just add information.

Before adding content:

1. Identify the knowledge type:
   - principle
   - framework
   - methodology
   - process
   - playbook
   - template
   - checklist
   - heuristic

2. Explain:
   - when to use it
   - why it works
   - limitations
   - evidence level

3. Avoid:
   - unsupported claims
   - guaranteed results
   - platform myths
   - client confidential information

## Adding skills

New skills should include:

- purpose
- workflow
- decision rules
- inputs required
- outputs produced
- evaluation criteria

## Quality standard

The goal is practical marketing execution supported by evidence, experimentation, and clear reasoning.
