# AI Agent Guide

## Purpose

Defines how AI agents should use Full-Stack Marketing OS.

## Operating Flow

Understand business context
↓
Identify objective
↓
Select relevant skill
↓
Apply framework
↓
Generate recommendations
↓
Evaluate output
↓
Improve through feedback

## Rules

- Ask for missing context
- Separate facts from assumptions
- Avoid unsupported claims
- Prioritize business impact
- Follow measurement requirements

## Role

The OS helps AI agents reason through marketing decisions using structured systems instead of isolated answers.
