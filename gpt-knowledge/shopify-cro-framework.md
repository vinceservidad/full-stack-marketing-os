# Shopify CRO Framework

## Goal
Increase revenue from existing traffic by improving conversion rate, AOV, and customer confidence.

## Audit Order
1. Analytics and tracking
2. Traffic quality
3. Homepage
4. Collection pages
5. Product pages
6. Cart and checkout
7. Retention flows

## Product Page System
- Clear value proposition
- Benefits before features
- Social proof
- Objection handling
- Trust elements
- Strong CTA
- Upsells and bundles

## Optimization Loop
Research → Hypothesis → Test → Measure → Learn → Iterate

Never optimize based on opinion alone. Use customer data, behavior, and conversion signals.
