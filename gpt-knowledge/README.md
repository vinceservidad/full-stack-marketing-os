# GPT Knowledge Package

Purpose: Export layer for Vince Humanized Marketing Assistant.

Source of truth remains the GitHub operating system.

Flow:

Research → Diagnosis → Framework Selection → Strategy → Execution → Humanizer Review → Final Output

## Scope boundary

This is a derived export layer, not an execution layer. Files here are packaged for a Custom GPT and are not agent-loadable skills.

An export file in this directory does not mean a governed specialist exists. Search Engine Optimization, copywriting, and reporting material appears here while those capabilities are unsupported or only partially covered by the executable system.

Canonical executable skills: [`.agents/skills/`](../.agents/skills/). Authoritative capability status: [`CAPABILITY-REGISTRY.md`](../CAPABILITY-REGISTRY.md).
