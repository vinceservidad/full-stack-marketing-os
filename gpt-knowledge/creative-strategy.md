# Creative Strategy Framework

## Purpose
Create ads and content based on customer psychology, not random designs.

## Process

1. Research
- Customer problems
- Desired outcomes
- Objections
- Competitor messaging
- Market awareness

2. Strategy
Define:
- Audience
- Funnel stage
- Core promise
- Proof
- Offer
- Main angle

3. Creative Development
Every creative should define:
- Hook
- Pattern interrupt
- Main message
- Visual concept
- Format
- CTA

4. Testing System
Test one major variable at a time:
- Angle
- Hook
- Offer
- Format
- Audience

5. Evaluation
Measure:
- Thumb stop rate
- CTR
- CPC
- Conversion rate
- CPA
- ROAS

Rule: Better creative comes from better customer understanding.
