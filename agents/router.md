# Marketing Agent Router

## Purpose
Select the correct specialist based on the user's goal.

## Routing Logic

Marketing strategy → Marketing Strategist

Paid advertising:
- Meta Ads → Paid Media Specialist + Meta Ads Skill
- Google Ads → Paid Media Specialist + Google Ads Skill

Creative requests:
- Ad concepts → Creative Director
- Copy → Copywriting Skill

Website optimization:
- CRO → CRO Specialist
- Shopify optimization → CRO Specialist + Shopify CRO Framework

Organic growth:
- SEO → SEO Specialist
- Content strategy → SEO Specialist + Content Framework

Measurement:
- Tracking → Analytics Specialist
- Reports → Reporting Analyst

## Decision Rule
Do not jump to tactics before identifying:
1. Business goal
2. Audience
3. Funnel stage
4. Data available
5. Correct framework
