# v1.10 Lifecycle Marketing Evaluations

Review the actual segmentation logic, trigger fallback discipline, deliverability judgment, and the boundary against copywriting. Wording matches alone do not pass.

## Ownership boundary

1. **Copy not written here:** A request for subject-line copy lands in lifecycle marketing. Pass only if it routes to `$copywriting`.
2. **Sequence design not written in copywriting:** A request to design trigger logic and cadence lands in copywriting. Pass only if it routes to `$lifecycle-marketing`.
3. **Not paid acquisition:** A request to generate net-new demand via email lands here. Pass only if this is corrected — lifecycle marketing develops captured demand, it does not acquire cold audiences.
4. **Incrementality routed:** A sequence's revenue is claimed fully incremental. Pass only if this is routed to `$tracking-measurement` rather than asserted.

## Segmentation and triggers

5. **Non-predictive segment:** A segment is defined by demographic only, with no behavioral distinction in the resulting message. Pass only if this is rejected as not a real segment.
6. **Stale segmentation:** A behavior-based segment is recomputed monthly against 30-day behavior. Pass only if the staleness is flagged.
7. **Missing suppression:** An abandoned-cart trigger has no suppression condition for a completed purchase. Pass only if this is treated as a defect before launch, not after a duplicate send.
8. **Late-data fallback:** A trigger depends on an event that sometimes arrives late. Pass only if a documented fallback is required, not assumed away.
9. **Trigger collision:** Multiple triggers could fire on the same customer action. Pass only if priority and mutual exclusion are addressed.
10. **Undersized segment:** A segment is too small for a dedicated sequence. Pass only if merging into a broader segment is considered rather than building a dedicated sequence anyway.

## Deliverability

11. **Volume spike:** Send volume is proposed to jump sharply with no ramp. Pass only if this is rejected in favor of a gradual increase.
12. **Purchased list:** A request to email a purchased or rented list arrives. Pass only if this is refused.
13. **Spam-complaint spike:** Spam complaints rise sharply. Pass only if this is treated as a stop condition, not a metric to watch passively.
14. **Authentication first:** A placement problem is diagnosed as a content issue before SPF/DKIM/DMARC are checked. Pass only if authentication is checked first.
15. **Reactive cadence increase:** A falling business outcome prompts a proposal to send more often without diagnosis. Pass only if this is rejected until the cause is diagnosed.

## Metrics and consent

16. **Open rate as outcome:** Open rate is reported as the business outcome. Pass only if it is treated as a diagnostic signal, not the outcome itself.
17. **Consent override:** A suppressed or unsubscribed contact is proposed for reactivation via a workaround. Pass only if this is refused without exception.
