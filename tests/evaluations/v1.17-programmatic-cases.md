# v1.17 Programmatic Evaluations

Review the actual supply-chain screening, verification independence, and evidence grading. Wording matches alone do not pass.

## Buying method

1. **Method not stated:** A campaign launches with no stated buying method or rationale. Pass only if open exchange, private marketplace, or programmatic guaranteed is stated with why.
2. **Open exchange treated as equivalent:** Open-exchange inventory is treated as equivalent in quality to a private marketplace deal with no evidence. Pass only if this is rejected.

## Supply-path optimization

3. **Headline cost only:** Inventory cost is judged by cost-per-impression alone with no check of intermediary fees. Pass only if total supply-chain cost is required.
4. **Unscreened scale-up:** Spend is scaled into an unscreened supply path. Pass only if screening is required before scaling.
5. **Category filter as sufficient:** A brand-safety category filter is treated as sufficient to exclude made-for-advertising sites. Pass only if this is rejected — MFA sites can pass keyword/category screens.
6. **Declared domain trusted:** A publisher domain is trusted as accurate with no independent confirmation where fraud risk is a concern. Pass only if this is flagged.
7. **Abrupt path change unevaluated:** Spend is abruptly consolidated toward "better" paths with no before/after check. Pass only if this is evaluated with the same discipline as any other change.

## Verification and fraud

8. **Self-reported figures accepted:** A DSP's or seller's self-reported viewability/IVT figures are accepted with no independent verification. Pass only if independent third-party verification is required.
9. **Clean basic IVT as proof:** A low basic invalid-traffic reading is treated as proof of overall inventory quality. Pass only if sophisticated IVT risk is acknowledged as still possible.
10. **Discrepancy averaged away:** A large, persistent gap between self-reported and independently verified metrics is averaged rather than investigated. Pass only if it is flagged as a signal requiring investigation.
11. **Stale verification config:** A verification vendor configuration from a prior period is assumed still adequate. Pass only if periodic reconfirmation is required.

## Targeting and measurement

12. **Cookie-dependent targeting assumed functional:** Third-party-cookie-based targeting is assumed to function as in a prior period with no check. Pass only if degraded or unavailable signal is disclosed.
13. **Served impression as outcome:** A served or viewable impression is presented as a caused business outcome. Pass only if it is graded on the causal evidence ladder instead.

## Boundary

14. **Not a walled-garden platform:** A Meta or TikTok campaign question lands here. Pass only if it is redirected to the correct platform skill.
