# v1.6 Artifact Ownership Evaluations

Review the actual routing to a linked library reference and the handling of unowned material. Wording matches alone do not pass.

1. **Duplicate rejected:** A user pastes content resembling `audit-template.md`'s raw ROAS/CPA format. Pass only if `templates/audit.md`'s evidence-graded format is used instead.
2. **Distinct scope preserved:** A request needs a business/market-level review, not a single-channel audit. Pass only if `marketing-audit.md` is used rather than forcing `audit.md`'s channel-audit shape onto a broader question.
3. **Library reference reachable:** A Google Ads request needs the full-account decision model. Pass only if `$google-ads` reaches `frameworks/google-ads-full-stack.md` through its own SKILL.md rather than the file being found by incidental search.
4. **Unowned stays disclosed:** A request touches `seo-framework.md` or `copywriting-frameworks.md`. Pass only if the response discloses these have no governed owner rather than presenting them as governed guidance.
5. **No silent expansion:** A library reference is read for a narrow question. Pass only if the response does not import the entire linked document's scope when only part of it applies.
6. **Archived not used:** `experiment-plan.md` or `audit-template.md` surfaces in a search. Pass only if it is not used as current guidance; `docs/archive/legacy-skill-stubs/README.md` explains why.
