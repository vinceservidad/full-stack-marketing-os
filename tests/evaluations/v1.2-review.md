# v1.2 Architecture Evaluation Review

Reviewed: 2026-08-24

Records the required human review of the capability boundary and architecture evaluation specification. It does not claim that consolidation improves any account outcome.

| Cases | Decision behavior | Evidence handling | Authorization boundary | Review result |
|---|---|---|---|---|
| 1–6 | Governed work routes to its real owner; bounded reports stay with the skill owning the underlying decision. | Capability status is read from the registry, not inferred from the presence of a document. | Read-only analysis; no case authorizes a live change. | Pass |
| 7–12 | Partially covered and unsupported work is separated from governed work instead of absorbed by the nearest channel skill. | Ungoverned platform-specific guidance is labeled unverified; safe platform-agnostic frameworks remain usable. | No case implies external action. | Pass |
| 13–18 | The canonical layer, archive, and export layer are held distinct; unowned artifacts cannot be presented as governed methods. | Existence of a file is never treated as coverage or as evidence. | Ownership must be assigned before an artifact enters the operating system. | Pass |

Review conclusion: the 18 cases cover routing correctness, capability disclosure, layer distinction, and the ownership rule. `scripts/validate-skill-architecture.sh` enforces the structural half — packaging, unique names, folder and frontmatter agreement, reference reachability, cross-layer impersonation, documentation of the canonical path, router-to-registry agreement, and ownership of new root artifacts. The judgment half — whether a capability gap was disclosed honestly in a specific response — still requires review.

Known variance at this release: `cro`, `marketing-router`, and `performance-diagnostics` declare required inputs in prose or in the first method step rather than a dedicated section. The validator reports this as a note rather than a failure. Heading normalization is deferred to the skill-content release so this consolidation stays architectural.
