# v1.15 Affiliate Marketing Evaluations

Review the actual attribution-bias handling, fraud/brand-bidding screening, and commission-structure discipline. Wording matches alone do not pass.

## Attribution integrity

1. **Tracked equals incremental:** Tracked commission volume is reported as the program's business contribution with no bias caveat. Pass only if the last-click structural bias is disclosed.
2. **Coupon partner assumed high-performing:** A coupon-site partner shows high tracked conversions. Pass only if coupon-code leakage is checked before crediting the partner as high-performing.
3. **Cross-device ignored:** Cross-device attribution gaps are assumed negligible with no check. Pass only if this assumption is flagged as unverified.
4. **Configuration change untreated:** A cookie-duration change is made and treated as a routine tweak. Pass only if it is evaluated with before/after discipline like any other measurement change.
5. **Incrementality asserted here:** A claim about the program's true incremental contribution is made without routing to `$tracking-measurement`. Pass only if this is rejected as outside this skill's method.

## Fraud and brand bidding

6. **Unrestricted brand bidding:** No policy exists on partners bidding branded terms. Pass only if this gap is flagged as a real financial exposure, not a minor omission.
7. **Brand-bidding violation tolerated:** A partner is found violating a stated brand-bidding policy and the recommendation is to let it continue for volume. Pass only if enforcement is required instead.
8. **Spike as success:** An unexplained conversion spike is treated as a signal to increase a partner's commission. Pass only if it is treated as a fraud-screening trigger first.
9. **Self-reported traffic accepted:** A flagged partner's self-reported traffic source is accepted with no independent verification. Pass only if independent confirmation is required.
10. **High conversion as proof of quality:** A suspiciously high conversion rate relative to category norms is accepted as evidence of partner quality. Pass only if it is treated as a screening signal instead.
11. **Enforcement without evidence:** A partner is suspended on one ambiguous signal with no stated evidence or confidence level. Pass only if evidence and confidence are required before enforcement.

## Commission structure

12. **Uniform rate by default:** Content partners and coupon partners are paid identically with no stated rationale. Pass only if this default is flagged as a decision that should be deliberate, not assumed.
13. **Network onboarded blindly:** A sub-affiliate network's full downstream partner list is onboarded with no oversight mechanism. Pass only if this is flagged as a compliance and fraud-exposure gap.

## Boundary

14. **Not influencer vetting:** A request to vet an individual creator relationship lands here. Pass only if it is distinguished from this skill's scope and routed appropriately.
15. **Disclosure cross-linked:** An affiliate partner who is also a content creator is in scope. Pass only if influencer marketing's disclosure discipline is applied in addition to affiliate-link disclosure.
