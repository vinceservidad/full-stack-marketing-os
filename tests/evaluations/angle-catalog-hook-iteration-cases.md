# Angle Catalog, Hook Types, and Creative Iteration Evaluations

Review the actual grounding discipline and iteration variable-isolation, not whether a category was named. Wording matches alone do not pass.

## Angle catalog and hook types

1. **Category without grounding:** A comparison angle is produced with no genuine competitive differentiation evidenced. Pass only if this is rejected.
2. **Quota over fit:** Every category in the catalog is executed regardless of evidence fit, to "cover the list." Pass only if this is rejected in favor of grounded selection.
3. **Fabricated proof hook:** A proof hook cites a rounded-up or invented customer count. Pass only if this is rejected as a substantiation failure.
4. **Hook-awareness mismatch:** A proof hook (assumes prior consideration) is used to open a cold, unaware audience's first touchpoint. Pass only if this mismatch is flagged.
5. **Hook as substitute for angle:** A strong contrarian hook is used to carry a weak or ungrounded underlying angle. Pass only if the angle's weakness is flagged, not excused by the hook.

## UGC narrative structure

6. **Fabricated testimonial:** A UGC-style piece is drafted as a testimonial with no real underlying customer experience. Pass only if this is rejected.
7. **Awareness-blind selection correctly applied:** UGC narrative is selected for a native-feeling format regardless of audience awareness stage. Pass only if this is treated as consistent with the structure's stated fit, not flagged as a mismatch.

## Creative iteration from a winner

8. **Win misjudged:** A cell is called a winner from CTR alone, ignoring business outcome and spend. Pass only if this is rejected per the skill's existing outcome standard.
9. **Multi-variable iteration:** A follow-up round changes hook, format, and offer simultaneously after a win. Pass only if this is rejected as making the result unattributable.
10. **Single win as durable pattern:** One winning round is treated as a proven, durable angle with no further replication. Pass only if replication is required first.
11. **Unedited cross-platform scaling:** A winning angle from one platform's test is scaled to a different platform with no platform-fit check. Pass only if this routes to the owning channel skill first.
12. **Ad conflated with angle:** A specific execution's win is treated as proof the angle itself is strong, with no attempt to separate execution quality from angle strength. Pass only if this conflation is flagged.
