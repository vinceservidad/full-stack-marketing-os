# v1.12 TikTok Ads Evaluations

Review the actual creative-fit judgment, Spark Ads versus in-feed decision, cadence discipline, and platform-currency check. Wording matches alone do not pass.

## Native creative fit

1. **Polish over-correction:** Repurposed high-production creative underperforms and "make it more polished" is proposed without checking fit. Pass only if native-format mismatch is considered before recommending more polish.
2. **Repurposed asset flagged:** A horizontal video is cropped for TikTok unedited. Pass only if this is flagged as a likely native-fit mismatch.
3. **Opening seconds checked:** A creative opens with a logo card. Pass only if this is flagged as reading like an ad rather than a native hook.
4. **Single-asset generalization:** One native-style asset performs well once. Pass only if this is treated as a hypothesis pending replication, not a standing creative rule.
5. **Concept work routed:** A request for new hook and angle development lands here. Pass only if it routes to `$creative-strategy`.

## Spark Ads vs in-feed

6. **Interchangeable treatment:** Spark Ads and standard in-feed are treated as the same decision. Pass only if this is rejected — the choice is stated with rationale.
7. **Comment moderation:** A Spark Ad is launched without a comment-moderation plan. Pass only if this is flagged as a brand-safety gap specific to Spark Ads.
8. **Organic-to-paid assumption:** A trending organic post's performance is assumed to predict its paid Spark Ads performance. Pass only if this assumption is rejected without evidence.

## Targeting and platform currency

9. **Stale targeting default:** Narrow manual targeting is recommended as a default without checking current platform guidance. Pass only if `PLATFORM-CURRENCY.md` is checked first.
10. **Undocumented algorithm claim:** A targeting-behavior claim is made with no source. Pass only if it is labeled inference, not fact.

## Fatigue and cadence

11. **Borrowed cadence:** A weekly refresh cadence from another platform is applied without observing this account's fatigue signal. Pass only if this is rejected as unobserved.
12. **Fatigue misattribution:** A performance decline is attributed to creative fatigue without checking targeting change, platform update, or seasonality. Pass only if competing explanations are checked first.
13. **Campaign-level masking:** Fatigue is assessed only at the campaign level while one creative's decline is masked by others. Pass only if creative-level tracking is required.
14. **Same-hook replacement:** A fatiguing asset is replaced with new creative using an identical hook and structure. Pass only if this is flagged as likely to fatigue on a similar timeline.
15. **Capacity constraint surfaced:** Refresh need exceeds production capacity and bears on a scaling decision. Pass only if this routes to `$optimization-scaling`'s creative-capacity gate.

## Boundary

16. **Not organic strategy:** A request for organic TikTok content strategy lands here. Pass only if it is declined as out of scope.
17. **Not another platform:** A Meta-specific targeting question lands here. Pass only if it is redirected.
