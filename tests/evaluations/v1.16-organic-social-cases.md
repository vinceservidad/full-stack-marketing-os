# v1.16 Organic Social Evaluations

Review the actual platform-currency discipline, cadence/capacity realism, and the boundary against paid amplification. Wording matches alone do not pass.

## Algorithm and platform currency

1. **Undocumented factor as fact:** A specific ranking factor is stated as fact with no source. Pass only if it is labeled by category (documented, account-observed, industry-inferred, unknown) instead.
2. **Stale distribution assumption:** A distribution mechanic from a prior period is carried forward without checking `PLATFORM-CURRENCY.md`. Pass only if this is checked first.
3. **Algorithm as default explanation:** A reach decline is attributed to "the algorithm changed" without checking account-specific causes first. Pass only if competing explanations are checked before crediting the algorithm.
4. **Cross-platform transfer:** A distribution pattern observed on one platform is claimed to apply to a different platform. Pass only if this is rejected without platform-specific evidence.
5. **Honest unknown:** A platform offers no visibility into a distribution change. Pass only if this is reported as an unknown rather than a constructed plausible explanation.

## Cadence and capacity

6. **Unsustainable cadence:** A platform-suggested cadence exceeds this account's actual production capacity. Pass only if it is checked against capacity, not adopted by default.
7. **Community management deprioritized:** Public comment response is treated as a low-priority backlog. Pass only if this is rejected given its reputational visibility.
8. **Cadence scaled without response capacity:** Posting volume increases with no corresponding increase in community-management staffing. Pass only if this mismatch is flagged.
9. **Single-post cadence conclusion:** One post's performance is used to justify a cadence change. Pass only if a sustained period is required instead.

## Business outcome and evidence

10. **Engagement as outcome:** Follower growth or engagement rate is presented as a business outcome. Pass only if it is treated as a delivery/audience-response signal requiring a stated attribution mechanism.
11. **Viral post generalized:** A single viral post's format is turned into a standing content pillar with no replication. Pass only if this is rejected as premature generalization.
12. **Native fit not checked:** A content format is reused unedited across platforms. Pass only if native fit is assessed per platform.

## Boundary

13. **Paid decision asserted here:** A decision to boost a post or run it as a paid ad is made within this skill. Pass only if it routes to the owning platform skill.
14. **Paid campaign question:** A question about paid Meta or TikTok campaign structure lands here. Pass only if it is redirected to the correct paid-channel skill.
