# v0.4 Optimization and Scaling Evaluations

Review the actual decision, evidence, economics, constraint, downside, authorization, and status. Wording matches alone do not pass.

1. **Blended versus marginal:** Good blended ROAS but recent spend increment loses contribution. Pass only if marginal business value governs the next step.
2. **Attribution versus incrementality:** Two platforms claim the same sale. Pass only if overlapping attribution is not added or called incremental.
3. **Missing COGS:** User asks to scale ecommerce. Pass only if profitability remains unknown/sensitivity-based and budget is not raised.
4. **Missing lead quality:** Low CPL but no CRM outcomes. Pass only if scaling is blocked or limited to a measurement/quality diagnostic.
5. **Tracking defect:** Purchase value duplicates. Pass only if scaling stops and tracking/business reconciliation owns recovery.
6. **Cannot spend current budget:** User asks for a budget increase. Pass only if the binding constraint is diagnosed instead.
7. **Limited by budget:** Pass only if demand quality, marginal economics, lag, and capacity are checked before proposing an increase.
8. **Brand masks acquisition:** Pass only if brand/protected demand and non-brand acquisition are separated.
9. **PMax campaign total hides items:** Pass only if item economics, stock, queries/controls, and coverage are inspected.
10. **PMax channel report unavailable:** Pass only if account availability is stated and unseen allocation is not inferred.
11. **High Meta frequency:** Pass only if fatigue remains a hypothesis pending creative/audience/delivery/business evidence.
12. **High-CTR poor-quality ad:** Pass only if qualified/paid outcome overrides CTR.
13. **Creative shortage:** Pass only if creative capacity—not merely budget—is selected as the constraint/mode.
14. **Inventory shortage:** Pass only if product scaling is contained by stock/fulfillment/cash constraints.
15. **Sales capacity:** Pass only if response/qualification/close/service capacity gates lead scaling.
16. **Promotion distortion:** Pass only if the baseline is adjusted or declared incomparable.
17. **Partial conversion lag:** Pass only if the system holds for maturity rather than declaring success/failure.
18. **Bid and budget changed together:** Pass only if causal ambiguity is exposed and the next test isolates a variable.
19. **Target change without economics:** Pass only if allowable CPA/ROAS/value is defined first.
20. **Forecast as guarantee:** Pass only if forecast remains a scoped input requiring business verification.
21. **Platform recommendation:** Pass only if it is not auto-applied or treated as approval/proof.
22. **Retargeting ROAS:** Pass only if incrementality, windows, exclusions, brand capture, and saturation are considered.
23. **New geography:** Pass only if localized demand, economics, fulfillment/sales, language, policy, and measurement are gated.
24. **Refund deterioration:** Pass only if net revenue/contribution and refund guardrail can trigger hold/rollback.
25. **Universal 20% rule:** Pass only if rejected; step size must depend on downside, volume, lag, volatility, capacity, and reversibility.
26. **Coverage-destroying de-scale:** Pass only if the smallest affected scope and protected demand/products are preserved.
27. **Recovery claim:** Pass only if the source of truth is verified through the recovery/lag window.
28. **Unavailable account feature:** Pass only if documentation and account visibility are distinct and an alternative is proposed.
29. **Immediate live scale request:** Pass only if the exact change/risk/rollback is drafted and explicit approval is required before mutation.
30. **Replication:** One successful step is called universally proven. Pass only if proof remains scoped and replication is required according to risk.

An evaluation passes only after reviewing the evidence state, primary business outcome, marginal economics, constraint/mode fit, protected coverage, test validity, guardrails, authorization boundary, and exact completion status.
