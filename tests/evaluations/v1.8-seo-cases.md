# v1.8 Search Engine Optimization Evaluations

Review the actual causal reasoning, technical/content sequencing, and capacity discipline. Wording matches alone do not pass.

## Causal discipline

1. **Algorithm update overlooked:** A ranking drop coincides with a documented broad-core update. Pass only if the update is checked and considered before attributing the drop to a specific site action.
2. **Seasonality ignored:** Traffic rises in Q4 after a content change. Pass only if year-over-year seasonality is checked before crediting the content change.
3. **Concurrent changes:** A content update and a technical deploy happened the same week. Pass only if isolation is stated as not possible rather than picking one cause.
4. **Evidence level stated:** A single ranking improvement follows an action. Pass only if this is graded no higher than C1 and not described as confirmed.
5. **Undocumented algorithm claim:** A ranking change is attributed to an unnamed algorithm mechanism. Pass only if this is labeled inference per `PLATFORM-CURRENCY.md`, not fact.
6. **Order of checks:** A ranking-change diagnosis skips straight to attributing a content change without checking the algorithm-update, seasonality, competitive, technical, and measurement explanations first. Pass only if this is rejected as an incomplete diagnosis.

## Technical and content sequencing

7. **Content before technical:** A site has unresolved indexation defects and content work is proposed anyway. Pass only if technical health is diagnosed first.
8. **Volume-only targeting:** A high-volume keyword with no intent match to the business is proposed as a content target. Pass only if this is rejected without a coverage-gap and intent justification.
9. **Consolidation over creation:** Thin, duplicate pages exist on a topic. Pass only if consolidation is considered rather than defaulting to new content.
10. **Capacity-exceeding plan:** A content plan exceeds stated production capacity. Pass only if it is phased or reduced, not proposed as-is.
11. **Structured data as guarantee:** Structured data is proposed as a way to directly raise ranking. Pass only if it is instead framed as eligibility for a rich result, with ranking effect measured separately.
12. **Risky technique:** A recommendation risks a manual action (undisclosed paid links, cloaking, doorway pages). Pass only if it is refused.

## Boundary and capacity

13. **Not paid search:** A user asks to improve Google Ads Quality Score using SEO techniques. Pass only if organic and paid search are not conflated.
14. **Live change discipline:** A large redirect migration or robots.txt change is proposed. Pass only if it is treated with the same rollback discipline as any other live change — exact scope, expected effect, downside, stop condition.
15. **Field over lab data:** Core Web Vitals lab data passes but field data is available and worse. Pass only if field data is reported as the governing evidence.
16. **Router correction:** A request for organic search work arrives. Pass only if it routes to `$seo` and is not described as unsupported.
