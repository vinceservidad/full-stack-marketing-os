# v1.14 Influencer Marketing Evaluations

Review the actual vetting discipline, compensation-structure fit, usage-rights and disclosure handling, and evidence grading. Wording matches alone do not pass.

## Vetting

1. **Follower count as proxy:** A creator is selected primarily on follower count. Pass only if this is rejected in favor of authenticity and fit evidence.
2. **Unverifiable audience claim:** A creator's audience demographics are self-reported with no verifiable source. Pass only if this is flagged rather than accepted as given.
3. **Topic-only fit:** A creator's content topic matches the product but audience fit against `$icp-jtbd` is not checked. Pass only if audience fit is assessed independently of topical relevance.
4. **Sudden growth unexamined:** A creator's follower count shows an unexplained spike. Pass only if this is treated as an authenticity flag requiring further check.
5. **Unproven creator, long commitment:** A long-term exclusive arrangement is proposed with an unproven creator with no prior trial. Pass only if a smaller reversible trial is recommended first.

## Compensation

6. **Goal-structure mismatch:** A commission-only structure is proposed for a pure awareness-goal partnership. Pass only if this misalignment is flagged.
7. **Untrackable commission:** Commission-based pay is promised on a metric that cannot actually be measured. Pass only if this is rejected before being offered.
8. **Gifting as free:** Gifting is treated as a zero-cost alternative with no stated content expectation. Pass only if the real cost and actual expectation are made explicit.
9. **Usage rights assumed included:** A usage-rights fee is assumed included in a base content fee with no confirmation. Pass only if this is treated as a separate term requiring explicit agreement.

## Usage rights and disclosure

10. **Unaddressed usage rights:** A partnership proceeds to content production with no usage-rights term defined. Pass only if this is flagged as a gap before production begins.
11. **Stale disclosure assumption:** A disclosure format used in a past campaign is reused without checking current requirements. Pass only if current compliance is verified rather than assumed.
12. **Disclosure discouraged for authenticity:** A request to omit or obscure disclosure to preserve an authentic feel arrives. Pass only if this is refused outright.
13. **Legal determination asserted:** A specific contract clause's legal sufficiency is asserted as final by this skill. Pass only if it is instead flagged for qualified legal review.

## Evidence and measurement

14. **Correlated sales as proof:** A sales increase during a campaign is presented as a proven incremental effect with no attribution mechanism. Pass only if this is capped low on the causal evidence ladder instead.
15. **No attribution mechanism, commission promised anyway:** Performance-based pay is promised without a unique code, link, or comparable measurement method in place. Pass only if this is rejected.

## Boundary

16. **Not paid media buying:** A request to manage a paid-media budget lands here. Pass only if it is redirected to the relevant paid-channel skill.
