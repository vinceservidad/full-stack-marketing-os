# v1.13 LinkedIn Ads Evaluations

Review the actual targeting-approach discipline, format-to-role fit, cost-benchmark handling, and lead-quality maturity check. Wording matches alone do not pass.

## Targeting

1. **Unconfirmed match rate:** Account-based reach is reported without checking the platform's actual match rate. Pass only if match rate is confirmed before reach is claimed.
2. **Indiscriminate account targeting:** A matched account is targeted in full with no role narrowing. Pass only if buyer-role evidence is used to narrow within the account.
3. **Assumed persona:** Attribute-based targeting is built from an assumed "decision-maker" title with no `$icp-jtbd` evidence. Pass only if this is rejected in favor of actual buying-committee evidence.
4. **Partial committee disclosed:** A campaign reaches only one buyer role in a multi-stakeholder purchase. Pass only if this is stated explicitly rather than presented as full coverage.
5. **Over-narrowed audience:** Firmographic filters are stacked until estimated audience size is too small to deliver. Pass only if this is flagged before launch.

## Format and cost

6. **Role-format mismatch:** A Message/Conversation Ad and a Lead Gen Form are treated as interchangeable regardless of buying-committee role or funnel stage. Pass only if format is matched to role and stage.
7. **Consumer benchmark applied:** LinkedIn cost per click is judged against a Meta or Google benchmark. Pass only if this is rejected as a false comparison.
8. **Friction blended:** Lead Gen Form and landing-page leads are compared as one cost-per-lead figure. Pass only if they are evaluated separately.

## Lead quality and sales cycle

9. **Volume as outcome:** Lead volume is presented as the business outcome. Pass only if it is treated as an early, weak signal requiring maturity check.
10. **Immature cohort judged final:** An early lead cohort's interim conversion rate is treated as a final quality verdict. Pass only if the open-share maturity check from `$retention-economics` is applied first.
11. **Role-blind lead quality:** Leads from different buyer roles are reported as one undifferentiated quality figure. Pass only if role is considered as a quality dimension.
12. **B2B seasonality ignored:** A lead or deal-velocity change coincides with a fiscal-quarter boundary. Pass only if this seasonality is checked before attributing the change to campaign performance.
13. **Incrementality asserted here:** A LinkedIn lead's incremental pipeline contribution is claimed without routing to `$tracking-measurement`. Pass only if this is rejected as outside this skill's method.

## Boundary

14. **Not a consumer channel:** A demographic-targeted consumer campaign question lands here. Pass only if it is redirected.
15. **Not CRM ownership:** A request to manage the underlying sales pipeline or Customer Relationship Management process lands here. Pass only if this is declined as outside scope.
