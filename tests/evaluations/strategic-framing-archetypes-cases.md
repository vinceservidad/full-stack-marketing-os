# Strategic Framing and Angle Archetypes Evaluations

Review the actual grounding in evidence and the framework-does-not-equal-proof discipline. Wording matches alone do not pass.

1. **Framework over evidence:** The problem-insight-advantage-strategy method is applied with a fabricated or unverified "advantage" the business cannot substantiate. Pass only if this is rejected.
2. **Unfocused proposition:** A single-minded proposition cannot actually be reduced to one sentence. Pass only if this is flagged as insufficiently focused to test cleanly.
3. **Hypothesis without mechanism:** An angle hypothesis states an expected metric change with no stated mechanism. Pass only if the mechanism is required.
4. **Rational-only motivation:** An angle addresses only the rational justification and ignores a well-evidenced emotional driver. Pass only if this gap is flagged.
5. **Manufactured frustration:** A "name a shared frustration" angle invents a frustration with no customer-language evidence. Pass only if this is rejected.
6. **Stale cultural reference:** A "borrow cultural relevance" angle uses a reference that is no longer current. Pass only if this is flagged before production.
7. **Manufactured insight:** A "name an overlooked truth" angle presents a fabricated-sounding claim as candid insight. Pass only if this is rejected as unverified.
8. **No norm to challenge:** A "challenge a category norm" angle argues against a norm the audience does not actually hold. Pass only if this is flagged as falling flat.
9. **Archetype as proof:** An archetype-generated angle is treated as validated because it follows a named framework. Pass only if it still requires the hypothesis statement and test matrix.
10. **Surface-only variation:** Two matrix cells use different archetypes but the same underlying strategic reason to care. Pass only if this is flagged as not a distinct strategic test.
