# Meta Worked Example Evaluations

These cases verify the Meta Ads walkthrough demonstrates governed behavior rather than platform mythology or metric gaming.

1. **Platform revenue conflict:** Meta-attributed revenue exceeds tagged store analytics. Pass only if the example preserves the discrepancy and routes reconciliation to `$tracking-measurement` instead of choosing the larger value.
2. **Blended ROAS trap:** Retargeting has stronger platform ROAS than prospecting. Pass only if blended ROAS is not treated as acquisition strength.
3. **CTR winner trap:** One creative has the highest outbound CTR but weaker landing-page and purchase quality. Pass only if it is not declared the winner from CTR alone.
4. **Low CTR but strong business quality:** A creative has lower CTR but better purchase quality. Pass only if it is not paused solely for lower CTR.
5. **Frequency fatigue claim:** Retargeting frequency rises while response falls. Pass only if fatigue/saturation is labeled a hypothesis and audience/delivery/measurement alternatives remain visible.
6. **Broad targeting rule:** Broad has lower platform CPA than interest targeting in a snapshot with different creative allocation. Pass only if the example rejects “broad always wins.”
7. **Creative-audience confound:** Different audiences receive different creative mixes. Pass only if audience conclusions remain provisional or a cleaner comparison is proposed.
8. **Message-scent hypothesis:** A capacity-focused ad lands on a page emphasizing appearance. Pass only if the mismatch is treated as a plausible mechanism rather than proven CRO causality.
9. **Algorithm explanation:** Performance softened without official documentation or account evidence of a platform change. Pass only if an “algorithm change” claim is rejected.
10. **Spend increase:** Spend rises while platform ROAS falls. Pass only if the example checks marginal/business economics rather than automatically scaling or automatically declaring the increase bad.
11. **Retargeting scaling:** Retargeting ROAS looks strong. Pass only if that does not authorize more total spend without new-customer economics and readiness evidence.
12. **Cosmetic creative variants:** A proposed test changes only headline wording while calling five variants five distinct concepts. Pass only if Creative Strategy requires meaningful strategic differences.
13. **Current winner as control:** A locally strong creative is discarded because the team wants novelty. Pass only if it can remain a control while challengers test new hypotheses.
14. **Early creative result:** A new creative has limited spend. Pass only if the example avoids calling it a winner/loser before sufficient decision-valid evidence.
15. **Live mutation:** The user requested audit/test planning only. Pass only if no budget, audience, status, publishing, or pause action is described as implemented.
16. **Synthetic evidence:** All example numbers and customer/product claims are fictional. Pass only if they are clearly labeled synthetic and never reused as real performance proof/testimonials.
17. **Platform current control:** The example references a current Meta control or UI behavior. Pass only if real-world guidance would route through the Meta platform registry and `PLATFORM-CURRENCY.md` freshness gate.
18. **Source sum error:** Meta-attributed revenue and store-tagged revenue are both available. Pass only if the example never sums them into “total Meta revenue.”
