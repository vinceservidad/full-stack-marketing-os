# v1.7 Marketing Reporting Evaluations

Review the actual combination behavior, definitional discipline, and refusal to re-derive underlying analysis. Wording matches alone do not pass.

## Ownership boundary

1. **No re-derivation:** A cross-channel report needs a diagnosis of why conversions fell. Pass only if `$performance-diagnostics` produces the diagnosis and reporting combines it, rather than reporting guessing at a cause.
2. **Bounded report stays put:** A single Google Ads audit report is requested. Pass only if `$google-ads` owns it directly, not routed through `$marketing-reporting`.
3. **Reconciliation routed:** Two channels' reported revenue overlaps. Pass only if `$tracking-measurement` owns the reconciliation, not resolved inside the report.
4. **Pacing stays with scaling:** A recurring report needs current spend-to-plan variance. Pass only if `$optimization-scaling`'s pacing output is combined, not recomputed inside the report.

## Evidence and definition discipline

5. **State preserved:** A source finding is `documented`, not `verified`. Pass only if the report does not present it as confirmed.
6. **No cross-platform summing:** Two platforms both report revenue for the same conversions. Pass only if the scorecard does not sum them into a combined total.
7. **One profit level:** A scorecard mixes gross revenue in one row and contribution margin in another with no label. Pass only if this is corrected to one named, consistent basis.
8. **Invalid comparison marked:** A period comparison fails the intake comparability check. Pass only if the row is marked rather than shown as a clean delta.
9. **Unverified benchmark:** A target has no stated source. Pass only if it is labeled unverified or omitted, not presented as a target.

## Cadence and revision

10. **Silent definition change:** A metric's definition changes between editions of a recurring report. Pass only if the change is disclosed in that edition, with both bases shown for the transition period.
11. **Reactive cadence:** One bad period tempts a report to publish early. Pass only if cadence is held unless a stated mid-cycle trigger (guardrail breach, tracking correction, material reforecast) applies.
12. **Revision disclosed:** A past figure is later corrected. Pass only if the current edition states what changed and which prior edition it corrects, rather than silently editing history.
13. **Dropped metric:** An unfavorable metric disappears from a recurring report without explanation. Pass only if this is flagged as a disclosure failure.

## Stakeholder communication

14. **Confidence preserved:** A provisional finding is translated for a non-specialist audience. Pass only if the plain-language version still reads as provisional, not confident.
15. **No implied approval:** A stakeholder summary is drafted before approval was granted. Pass only if it does not imply the action was already approved.
16. **Unknown retained:** A source skill flagged a decision-reversing unknown. Pass only if the stakeholder version keeps it rather than dropping it for a cleaner narrative.
