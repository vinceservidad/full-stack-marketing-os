# v1.5 Retention Economics and Pacing Evaluations

Review the actual model choice, definitional discipline, and boundary between an operational correction and a scaling decision. Wording matches alone do not pass.

## Lifetime value and payback

1. **Historical versus predictive:** A cohort is 60 days into an 18-month typical lifetime. Pass only if any lifetime value reported is labeled predictive with a stated confidence, not presented as realized.
2. **Profit level named:** A lifetime value figure is requested. Pass only if the profit level and included costs are stated, not left implicit.
3. **Mismatched horizon:** A 90-day lifetime value is compared against a 12-month payback period. Pass only if the mismatch is flagged rather than compared directly.
4. **Gross versus contribution:** Gross lifetime value is compared against contribution-based acquisition cost. Pass only if this is rejected as inflating apparent profitability.
5. **Platform-attributed cost:** Acquisition cost is only available as platform-attributed. Pass only if payback is labeled provisional per the causal evidence ladder.
6. **Blended masking:** A blended lifetime value hides an unprofitable channel. Pass only if segmented figures are required before a channel-level conclusion.
7. **Single cohort:** One cohort shows improved retention. Pass only if it is treated as a hypothesis pending replication, not an established trend.

## Cohort and retention discipline

8. **Unobserved maturity:** A cohort acquired last month has no period-11 data. Pass only if any period-11 figure is marked projected, not observed.
9. **Averaging across ages:** Retention is averaged across cohorts of different age. Pass only if this is rejected as masking the current trend.
10. **Logo versus revenue churn:** A business retains most accounts but loses revenue. Pass only if both churn types are reported and not conflated.
11. **Lapse window stated:** A repeat-purchase rate is reported. Pass only if the inactivity window used is stated.
12. **Open leads:** A lead cohort's conversion rate is reported while many leads remain open. Pass only if the open share is disclosed and the figure is not treated as final.
13. **Survivorship bias:** A lead cohort is defined by opportunity-creation date instead of lead-creation date. Pass only if this is identified as biasing the cohort toward leads that already progressed.
14. **Premature scale-down:** A lead-generation channel's recent cohorts show lower conversion. Pass only if incomplete maturation is checked before concluding quality declined.

## Pacing boundary

15. **Attribute before correcting:** Spend is behind pace. Pass only if a cause is attributed before a budget change is proposed.
16. **Early-period noise:** Variance appears on day two of a thirty-day period. Pass only if it is not treated as decisive.
17. **Pacing versus scaling:** A pacing correction would require exceeding the approved budget. Pass only if this is treated as a scaling decision requiring the full gate set, not a pacing note.
18. **Source-of-truth outcome:** Outcome pacing is computed from a platform-reported conversion count. Pass only if this is flagged as unreconciled rather than paced against directly.
19. **Predictive LTV does not authorize scaling:** A predictive lifetime value model looks favorable. Pass only if it does not by itself satisfy the marginal-evidence gate.
20. **Reforecast logged:** A reforecast is issued. Pass only if its date and cause are recorded, not just the revised number.
