# v1.18 Public Relations Evaluations

Review the actual newsworthiness assessment, crisis discipline, and evidence limits. Wording matches alone do not pass.

## Newsworthiness and pitching

1. **No news hook, pitch proceeds anyway:** A pitch is built with no genuine newsworthiness. Pass only if this is named rather than proceeding on pitch quality alone.
2. **Generic media list:** Outreach uses a broad, generic media list with no fit check. Pass only if fit to the story and audience is required.
3. **Fabricated claim to press:** A statement to media includes an unsubstantiated benchmark or credential. Pass only if this is rejected per the standard applied elsewhere in this system.
4. **Message control assumed:** A pitch's framing is assumed to appear verbatim in resulting coverage. Pass only if editorial independence is acknowledged instead.

## Crisis communications

5. **Speculation under pressure:** A crisis response fills a factual gap with a plausible but unverified explanation. Pass only if this is rejected in favor of stating the gap explicitly.
6. **Sequential legal review:** Legal-exposure review happens only after a communications response is drafted and ready to send. Pass only if parallel review is required instead.
7. **Silence as default:** No response is issued while awaiting complete information. Pass only if an accurate, appropriately scoped partial response is preferred over silence.
8. **Missed update commitment:** A stated update deadline passes with no communication. Pass only if this is flagged as a credibility failure.
9. **Hindsight bias in review:** An after-action review judges a decision by information not available at the time. Pass only if this is rejected in favor of assessing what was knowable in the moment.
10. **No escalation path:** A crisis response proceeds with no clarity on who can approve it. Pass only if establishing the approval chain is required as a first step.

## Measurement and evidence

11. **Mentions as outcome:** Media-mention volume is presented as a business outcome. Pass only if it is treated as a delivery signal only.
12. **Correlated timing as proof:** A traffic spike the same day as a placement is claimed as proven causal impact. Pass only if this is capped at correlation-level evidence (C1) absent a controlled design.
13. **Sentiment as precise:** An automated sentiment score is presented without its known accuracy limitations. Pass only if the limitations are disclosed.
14. **Composite score obscures components:** Share of voice, sentiment, and volume are blended into one score with no breakdown. Pass only if the components are stated separately.
15. **Incrementality asserted here:** A causal claim about the program's revenue impact is made without routing to `$tracking-measurement`. Pass only if this is rejected as outside this skill's method.

## Boundary and escalation

16. **Legal determination asserted:** This skill declares a specific statement legally sufficient. Pass only if it is instead flagged for qualified legal review.
17. **Community-management escalation:** A pattern of public complaints on organic social escalates toward a reputational concern. Pass only if it routes from `$organic-social`'s routine handling to this skill's crisis discipline.
