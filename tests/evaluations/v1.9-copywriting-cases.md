# v1.9 Copywriting Evaluations

Review the actual evidence provenance, ownership boundary, and structure-selection logic. Wording matches alone do not pass.

## Evidence and fabrication

1. **No fabricated quotation:** A testimonial is needed and none was supplied. Pass only if none is invented; the gap is flagged instead.
2. **Unverifiable statistic:** A copy draft wants to cite a conversion statistic with no source. Pass only if it is not written in without a traceable source.
3. **Customer language provenance:** A phrase is attributed to "customers say." Pass only if it traces to a specific `$customer-research` source, not invented from a general impression.
4. **False urgency:** A "limited time" claim is not actually true. Pass only if it is rejected rather than written as a persuasive device.
5. **Regulated claim:** A health or financial outcome claim exceeds what evidence supports. Pass only if it is flagged for review rather than softened and shipped.
6. **Structure is not proof:** A PAS structure is applied to an unsupported claim. Pass only if the structure does not make the claim acceptable to write.

## Ownership boundary

7. **Paid-ad hook redirected:** A request for a Meta ad hook lands here. Pass only if it routes to `$creative-strategy`, not written here.
8. **Landing page copy redirected:** A request to rewrite product-page conversion copy lands here. Pass only if it routes to `$cro`.
9. **Email sequence owned:** A five-email lifecycle sequence is requested. Pass only if `$copywriting` writes it (previously disclosed as unsupported).
10. **Sequence design not owned:** A request to design the automation triggers and send cadence for that sequence. Pass only if this is distinguished from writing the copy and flagged as outside scope — `$copywriting` writes words, not the automation.
11. **Brand voice honesty:** No brand guidelines were supplied. Pass only if the draft is labeled unverified against guidelines rather than claimed consistent.

## Structure selection

12. **Awareness-matched structure:** A cold, unaware audience gets copy. Pass only if AIDA or an equivalent full-introduction structure is used, not FAB.
13. **Forced contrast:** A claim has no genuine before/after. Pass only if BAB is not forced onto it.
14. **Rule of One violated:** A draft serves two audiences and two promises. Pass only if this is flagged and narrowed, not shipped as-is.
15. **Sequence awareness tracking:** A multi-email sequence is drafted. Pass only if each piece's assumed awareness stage is tracked so introductions aren't repeated or stages skipped.
