# v1.11 YouTube Ads Evaluations

Review the actual objective-to-measurement match, format fit, and evidence grading. Wording matches alone do not pass.

## Objective and measurement match

1. **Awareness judged on conversion:** A brand-awareness campaign is evaluated on conversion rate. Pass only if this mismatch is flagged and brand lift is required instead.
2. **Direct response judged on reach:** A direct-response campaign is evaluated on view-through reach alone. Pass only if a conversion-based measurement is required.
3. **View-through as click-through:** A view-through conversion is presented as equivalent to a click-through one. Pass only if this is rejected and graded separately.
4. **Causal grading:** A view-through effect claim is made. Pass only if it is capped at C1–C2 absent a designed incrementality test.
5. **No summed totals:** View-through and click-through conversions are summed into one incremental total. Pass only if this is rejected as overstating effect.
6. **Brand lift skepticism:** A platform-run brand lift study is offered as independent proof. Pass only if the same seller-grades-own-work caution from `$tracking-measurement` is applied.
7. **Delivery not outcome:** View rate or completion rate is presented as the business outcome. Pass only if it is treated as a delivery/engagement signal requiring a separate business-outcome metric.

## Format fit

8. **Bumper overload:** A message requiring explanation is forced into a 6-second bumper. Pass only if this is rejected as incompressible to the format.
9. **Skip-blind creative:** A skippable in-stream asset does not communicate its message in the first five seconds. Pass only if this is flagged before launch.
10. **Unedited reuse:** A 30-second asset is trimmed to a bumper without redesign. Pass only if this is rejected as likely to lose the message, not just the length.
11. **Discovery thumbnail:** An in-feed/discovery ad's thumbnail and title are treated as an afterthought. Pass only if they are held to the same rigor as a search ad headline.
12. **Outstream audio-only:** An outstream creative relies on audio narration alone. Pass only if this is flagged since outstream is typically sound-off by default.
13. **Non-skippable as a crutch:** Non-skippable format is chosen to force completion of weak creative. Pass only if this is rejected as not a fix for the creative problem.

## Boundary and settings

14. **Not Google Ads mechanics:** A request for Search campaign structure lands in YouTube Ads. Pass only if it routes to `$google-ads`.
15. **Not organic YouTube:** A request for organic channel growth strategy lands here. Pass only if it is declined as out of scope.
16. **Brand safety preserved:** A request to loosen content-adjacency settings for reach arrives with no explicit approval. Pass only if the settings are preserved.
17. **Definition not reused unmodified:** A Search conversion definition is applied unmodified to a video campaign's objective. Pass only if this is flagged and a video-appropriate definition is required.
