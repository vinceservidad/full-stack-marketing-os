# Static DTC Creative Direction Evaluations

Review production-direction quality and truthfulness, not whether an asset merely looks polished.

1. **Generic premium request:** A brief says “make a premium DTC ad” with no audience tension, hierarchy, product role, or brand codes. Pass only if it is returned as incomplete rather than expanded into generic black, serif, or luxury imagery.
2. **Emotion without situation:** The direction specifies “evoke confidence” but names no audience situation or felt shift. Pass only if the missing emotional job is flagged.
3. **Reference copied:** A supplied competitor ad is translated into the same composition, distinctive layout, and adapted headline. Pass only if copying/trade-dress risk is flagged and the brief is redirected to extract observable patterns instead.
4. **Pattern claimed proven:** A reviewer says a large hook and product cutout are “proven to convert” solely because several references use them. Pass only if observation is separated from causal evidence.
5. **No reading order:** A render brief includes product, testimonial, offer, headline, badge, and CTA but does not state first/second/third read. Pass only if hierarchy is required before generation.
6. **Generic typography:** The type direction is “clean bold font, readable text.” Pass only if it is rejected as insufficient without exact copy, line breaks, hierarchy, relative scale, category, contrast, and placement.
7. **Image-model text failure:** A brief relies on the image model to render a detailed price, disclaimer, and four-line hook exactly. Pass only if it directs visual-base generation separately from precise text overlay.
8. **Unsupported visual proof:** A static ad uses an invented five-star rating and “dermatologist approved” seal because it needs credibility. Pass only if both are rejected pending evidence.
9. **Premium stereotype:** The direction automatically uses a dark marble background and serif type because the product is expensive. Pass only if it requires brand-specific codes and a message-based rationale.
10. **Rendered but not validated:** An attractive export is described as finished despite illegible proof at placement size and product cropped out in one adaptation. Pass only if it remains draft and requires preflight.
11. **Creative copy ownership:** A request for static paid-ad headline, layout hierarchy, and type overlay is routed only to $copywriting. Pass only if it routes to $creative-strategy, with $copywriting support only for longer-form or brand copy outside the paid-ad concept.
12. **Controlled learning:** Two static variants simultaneously change angle, product scene, hook, typography, and offer. Pass only if this is rejected as an uncontrolled learning cell.
13. **4:5 master with no square plan:** A 1080×1350 asset will also be reused as 1:1, but the brief gives no square-safe composition. Pass only if it defines a centered 1080×1080 cross-crop core before production.
14. **4:5 geometry:** A 1080×1350 master is described as having a 100 px top and bottom square-crop band. Pass only if the geometry is corrected to 135 px top and 135 px bottom for a centered 1080×1080 derivative.
15. **Headline in crop-risk band:** The full 4:5 looks good, but the headline sits mostly in the top 100 px. Pass only if the asset fails 1:1 cross-crop preflight and the critical hook is moved into the square core.
16. **CTA outside square core:** The CTA is entirely in the bottom 120 px of the 4:5 master. Pass only if it fails a required 1:1 derivative because the action meaning does not survive the crop.
17. **Decorative bleed outside square:** Background texture, shadows, and nonessential props extend into the top/bottom crop bands while all critical meaning survives the square crop. Pass only if this is allowed rather than forcing every pixel into 1:1.
18. **Partial product bleed:** A decorative package edge extends beyond the square core but the product remains unmistakable and no material claim is lost in 1:1. Pass only if this may be accepted after derivative validation.
19. **Square core treated as universal Meta safe area:** A brief says “Meta’s safe zone is always 1:1” solely because this methodology uses a square core. Pass only if the platform claim is rejected; 1:1 is an internal cross-crop resilience rule and current placement-specific UI safety must be checked separately.
20. **Guide-only validation:** The designer keeps text inside square guides but never previews the actual 1:1 export. Pass only if the workflow still requires rendering/previewing the derivative and checking hook, product, proof, CTA, and subject meaning.
21. **No square derivative required:** A static asset is confirmed to serve only in one 4:5 placement, and no square reuse/crop is expected. Pass only if the system does not force a 1:1 core from habit; it should apply the actual placement-safe area instead.
22. **Face cropped after derivative:** A model’s face is partly outside the 1:1 core and the square crop removes the expression that carries the emotional job. Pass only if it fails cross-crop preflight even though the headline and CTA remain visible.
23. **Proof survives but disclaimer does not:** A claim remains visible in the square crop but its required qualifying text is outside the core. Pass only if the crop fails because material claim meaning changed.
24. **Platform overlay conflict:** All content fits the centered 1:1 core, but a current placement UI element would cover the CTA. Pass only if the square core is treated as insufficient and current channel/placement-safe guidance is applied.
