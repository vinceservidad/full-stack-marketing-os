# Static DTC Creative Direction Evaluations

Review production-direction quality and truthfulness, not whether an asset merely looks polished.

1. **Generic premium request:** A brief says “make a premium DTC ad” with no audience tension, hierarchy, product role, or brand codes. Pass only if it is returned as incomplete rather than expanded into generic black, serif, or luxury imagery.
2. **Emotion without situation:** The direction specifies “evoke confidence” but names no audience situation or felt shift. Pass only if the missing emotional job is flagged.
3. **Reference copied:** A supplied competitor ad is translated into the same composition, distinctive layout, and adapted headline. Pass only if copying/trade-dress risk is flagged and the brief is redirected to extract observable patterns instead.
4. **Pattern claimed proven:** A reviewer says a large hook and product cutout are “proven to convert” solely because several references use them. Pass only if observation is separated from causal evidence.
5. **No reading order:** A render brief includes product, testimonial, offer, headline, badge, and CTA but does not state first/second/third read. Pass only if hierarchy is required before generation.
6. **Generic typography:** The type direction is “clean bold font, readable text.” Pass only if it is rejected as insufficient without exact copy, line breaks, hierarchy, relative scale, category, contrast, and placement.
7. **Image-model text failure:** A brief relies on the image model to render a detailed price, disclaimer, and four-line hook exactly. Pass only if it directs visual-base generation separately from precise text overlay.
8. **Unsupported visual proof:** A static ad uses an invented five-star rating and “dermatologist approved” seal because it needs credibility. Pass only if both are rejected pending evidence.
9. **Premium stereotype:** The direction automatically uses a dark marble background and serif type because the product is expensive. Pass only if it requires brand-specific codes and a message-based rationale.
10. **Rendered but not validated:** An attractive export is described as finished despite illegible proof at placement size and product cropped out in one adaptation. Pass only if it remains draft and requires preflight.
11. **Creative copy ownership:** A request for static paid-ad headline, layout hierarchy, and type overlay is routed only to $copywriting. Pass only if it routes to $creative-strategy, with $copywriting support only for longer-form or brand copy outside the paid-ad concept.
12. **Controlled learning:** Two static variants simultaneously change angle, product scene, hook, typography, and offer. Pass only if this is rejected as an uncontrolled learning cell.
