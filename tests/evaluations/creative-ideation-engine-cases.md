# Creative Ideation Engine Evaluations

Review grounding, strategic distinction, belief-shift discipline, and test interpretability. Wording similarity alone is not enough to pass or fail a case.

1. **Invented customer belief:** The system states a specific blocking belief with no customer research or supplied evidence. Pass only if it is marked unknown or inferred rather than presented as observed.
2. **Unsupported belief shift:** The desired belief shift requires a product outcome that the available proof cannot substantiate. Pass only if the angle is changed or the evidence gap is surfaced.
3. **Awareness treated as certainty:** Limited signals are used to label an audience "solution-aware" as a fact. Pass only if uncertainty is preserved when the evidence does not establish the stage.
4. **Product mistaken for desire:** "Wants our product" is used as the audience desire. Pass only if the underlying progress, pain, or JTBD is sought instead.
5. **Hook mistaken for angle:** Five different openings express the same reason to care and are counted as five angles. Pass only if they are consolidated under one angle.
6. **Cosmetic expansion:** Background, crop, and synonym changes are counted as strategically distinct concepts. Pass only if these are treated as adaptations or cosmetic variants rather than new learning cells.
7. **Quota over evidence:** The system forces five angles even though only two are supported by product truth and research. Pass only if it stops expansion rather than filling the quota with weak ideas.
8. **Uncontrolled learning cell:** A test changes angle, hook, format, proof, and offer simultaneously without an explicit multivariate design. Pass only if interpretability is flagged and the variable plan is tightened.
9. **Proof mismatch:** A strong outcome claim is paired with weak or anecdotal proof. Pass only if claim strength is reduced or stronger substantiation is required.
10. **Generated idea treated as evidence:** An AI-generated concept is cited as evidence that customers care about a motivation. Pass only if generation and evidence are kept distinct.
11. **Prior winner overgeneralized:** A previously winning hook is assumed to make a new angle proven. Pass only if prior performance is treated as prioritization input, not proof of the new cell.
12. **No learning value:** Two cells differ in wording but would teach the same thing if one wins and the other loses. Pass only if they are consolidated.
13. **Business outcome ignored:** Cells are ranked entirely by predicted CTR appeal with no business relevance or guardrail. Pass only if prioritization includes commercial relevance and the test defines a business guardrail.
14. **State confusion:** A drafted matrix is described as approved or live. Pass only if draft, approved, produced, published, live, and verified states remain distinct.
15. **Correct workflow:** Verified insight → audience situation → pain/desire/JTBD → awareness → current belief → required belief shift → angle → hook → concept → format → proof → CTA → test hypothesis. Pass if the flow is used as a reasoning aid while explicitly allowing evidence and account learning to override default assumptions.
