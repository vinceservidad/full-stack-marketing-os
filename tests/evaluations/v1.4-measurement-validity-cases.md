# v1.4 Measurement Validity and Incrementality Evaluations

Review the actual method selection, evidence grading, scope statement, and authorization boundary. Wording matches alone do not pass.

## Evidence grading

1. **Attribution as proof:** Platform reports 6x ROAS over twelve months. Pass only if this stays C0 and supports no causal claim regardless of volume or consistency.
2. **Weakest element:** A randomized test ran with a known contaminated control. Pass only if it is not graded C4.
3. **Scope statement:** A holdout showed lift at one spend level. Pass only if the estimate is scoped to that population, period, and spend range and is not generalized.
4. **Unlabeled claim:** A causal statement carries no evidence level. Pass only if it is treated as C0.
5. **Null result:** A test returned no detectable effect. Pass only if it is reported with its minimum detectable effect and not read as proof of no effect.
6. **Level versus decision:** The achievable level is below what a sustained budget increase requires. Pass only if the commitment is lowered, made reversible, or the test is run first.
7. **Scaling gate:** S4 is claimed from platform-attributed performance. Pass only if this is rejected and C3 or above is required.

## Method selection

8. **Constraints choose the method:** Users cannot be split cleanly but regions are independent. Pass only if a geo design is selected over a user holdout.
9. **Integrity first:** Measurement integrity is unresolved. Pass only if no causal test is designed until it is fixed.
10. **Underpowered test:** Expected effect is below what the design can detect. Pass only if the test is not run as though it will be informative.
11. **Control cannot be held:** The holdback would be released before conversion lag matures. Pass only if the design is rejected or changed.
12. **Holdback cost:** A large holdout is proposed for a small decision. Pass only if forgone revenue is counted against the decision's value.
13. **Coincident event:** A promotion overlaps the window. Pass only if it is excluded, the window moves, or the result is declared confounded.
14. **Unknown input:** A selection input was never supplied. Pass only if it is recorded unknown rather than defaulted.
15. **Switchback carryover:** Effect persists beyond the switching interval. Pass only if carryover is stated and the interval exceeds it.

## Platform lift and modeling

16. **Self-graded study:** Platform lift is offered as independent verification of that platform's attribution. Pass only if it is not treated as independent.
17. **Modeled outcome:** A lift study measures modeled conversions. Pass only if the level is capped below C4.
18. **Cross-platform comparison:** Two platforms' lift results are compared or added. Pass only if this is rejected as non-commensurable.
19. **No spend variation:** A channel held at constant budget appears in a Marketing Mix Model. Pass only if its contribution is not reported as estimated.
20. **Specification sensitivity:** Contribution shifts materially under a reasonable alternative specification. Pass only if it is not treated as decision-grade.
21. **Extrapolation:** A model is used to justify spend beyond its observed range. Pass only if this is refused.
22. **Model versus experiment:** A model disagrees with a randomized result. Pass only if the experiment governs within its scope and the model is calibrated, not the reverse.

## Triangulation

23. **No summing:** Attributed conversions across platforms are totalled. Pass only if this is rejected as double counting.
24. **No averaging:** An experimental estimate is averaged with an attributed one. Pass only if this is rejected as combining different quantities.
25. **Shared defect:** Two sources agree because both read the same broken tag. Pass only if they are not treated as independent corroboration.
26. **Expected disagreement:** A randomized result contradicts platform attribution. Pass only if this is expected rather than reconciled away.
27. **Overall level:** Several sources of mixed level support a claim. Pass only if the claim takes the level of the evidence actually supporting it.
28. **Unresolved conflict:** Triangulation cannot resolve a disagreement. Pass only if the range and competing explanations are reported rather than one source selected.
