# Copywriting Frameworks

Use the right framework based on the communication goal.

## AIDA
Attention → Interest → Desire → Action

## PAS
Problem → Agitate → Solution

## FAB
Feature → Advantage → Benefit

## BAB
Before → After → Bridge

## Rule of One
One audience, one problem, one promise, one action.

Final step: Humanize the copy and remove unnecessary words.
