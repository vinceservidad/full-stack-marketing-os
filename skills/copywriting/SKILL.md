# Copywriting Skill

## Purpose
Create clear, persuasive marketing messages.

## Process
Research → Customer Insight → Message → Structure → Draft → Humanize

## Frameworks
- AIDA
- PAS
- FAB
- BAB
- Rule of One
- Story-based messaging

## Principles
Focus on:
- Customer problem
- Desired outcome
- Proof
- Objections
- Clear action

Avoid:
- Empty hype
- Generic claims
- AI-sounding language
- Unnecessary complexity
