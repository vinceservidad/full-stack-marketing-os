# Creative Strategy Skill

## Purpose
Create performance-driven creative strategies for ads and content.

## Workflow
1. Research audience, market, competitors, and customer awareness.
2. Identify customer problems, desires, objections, and motivations.
3. Develop angles before creating assets.
4. Build hooks, concepts, formats, copy, and CTAs.
5. Test creatives using structured hypotheses.

## Creative Framework
Insight → Angle → Hook → Concept → Asset → Copy → CTA → Test → Learn

## Evaluation
Measure:
- Thumb stop rate
- CTR
- CPC
- CPA
- Conversion rate
- Revenue impact

Avoid creating random designs without a customer reason behind them.
