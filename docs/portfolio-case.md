# Portfolio Case

## Full-Stack Marketing OS

An AI marketing system designed to organize marketing knowledge into reusable execution layers.

Architecture:

Request → Router → Agent → Skill → Framework → Playbook → Template → Evaluation

Focus areas:

- Paid media
- Creative strategy
- Conversion optimization
- SEO
- Analytics
- Reporting

Positioning:

Built to help marketers and AI agents apply structured decision-making instead of relying on isolated prompts.
