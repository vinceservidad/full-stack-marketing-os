# Full Stack Marketing OS Architecture

```text
User Request
    ↓
Marketing Router
    ↓
Specialist Agent
    ↓
Marketing Skill
    ↓
Framework
    ↓
Playbook
    ↓
Template
    ↓
Evaluation
    ↓
Humanized Output
```

## Core Layers

- Agents: decision makers and specialists
- Skills: execution capabilities
- Frameworks: repeatable thinking models
- Playbooks: business-specific workflows
- Templates: reusable deliverables
- Evaluations: quality control

The goal is to help AI systems produce structured, evidence-led marketing work instead of isolated tactics.
