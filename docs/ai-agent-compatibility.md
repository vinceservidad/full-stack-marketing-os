# AI Agent Compatibility

## Purpose

Full-Stack Marketing OS is designed to work as a knowledge and workflow layer for different AI environments.

## ChatGPT

Use the repository knowledge as the foundation for Custom GPT instructions and uploaded knowledge files.

Recommended flow:

Request → Router → Skill → Framework → Playbook → Template → Evaluation

## Claude Code

Use skills as agent instructions. The repository structure allows Claude Code to discover marketing capabilities and apply the correct workflow.

## Codex / Coding Agents

Use the repository as a versioned source of truth. Changes should update frameworks, skills, templates, and evaluations together.

## General Agent Rules

- Choose the correct skill before giving tactics.
- Use evidence before assumptions.
- Separate facts, hypotheses, and recommendations.
- Do not invent client results or platform behavior.
- Review output quality before delivery.
