# Public Launch Guide

## Goal

This repository is designed to demonstrate a structured AI marketing operating system, not a collection of disconnected prompts.

## Before Publishing

Review:

- Remove client confidential information
- Remove private campaign data
- Keep examples anonymized
- Verify framework sources
- Review claims and results

## Public Positioning

Describe the project as:

> An open-source AI marketing operating system combining skills, frameworks, playbooks, templates, and evaluation methods.

## Content That Belongs Publicly

- General marketing frameworks
- AI agent workflows
- Reusable templates
- Educational examples
- Documentation

## Content That Should Stay Private

- Client account data
- Internal audits
- Private SOPs
- Proprietary experiments
- Sensitive business information
