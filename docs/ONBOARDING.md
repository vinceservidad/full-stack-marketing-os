# Marketing OS Onboarding

## Purpose

This guide explains how to start using Full-Stack Marketing OS.

## Workflow

1. Define the business objective.
2. Identify the customer and market context.
3. Select the correct skill.
4. Apply the relevant framework.
5. Use the playbook and template.
6. Evaluate the output.
7. Capture learnings.

## Core Principles

- Business goals before platform settings.
- Evidence before assumptions.
- Strategy before tactics.
- Testing before scaling.
- Human judgment before automation.
