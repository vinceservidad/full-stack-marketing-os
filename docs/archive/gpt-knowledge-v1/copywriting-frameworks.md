# Copywriting Frameworks

## Rule of One
One audience, one problem, one promise, one offer, one CTA.

## AIDA
Attention → Interest → Desire → Action

Use for:
- Ads
- Landing pages
- Email

## PAS
Problem → Agitate → Solution

Use when the customer has a strong pain point.

## FAB
Features → Advantages → Benefits

Translate product details into customer outcomes.

## BAB
Before → After → Bridge

Show the current situation, desired outcome, and solution path.

## Copy Principles
- Lead with customer value
- Use proof when available
- Match awareness level
- Avoid unsupported claims
- Make the next action clear
