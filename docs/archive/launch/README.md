announcements, GitHub setup notes, repository metadata, and the launch-asset
drafts. It is kept for history and is **excluded from active retrieval** along
with the rest of `docs/archive/` (see `ARCHITECTURE.md`).

Skill → Humanized Output" pipeline the system no longer uses. The live versions
