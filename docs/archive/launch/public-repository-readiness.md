# Public Repository Readiness

Before making Full-Stack Marketing OS public:

## Keep Public

- General marketing frameworks
- Agent instructions
- Skills
- Playbooks
- Templates
- Educational examples
- Documentation

## Keep Private

- Client names and confidential data
- Account screenshots
- Internal reports
- Private SOPs
- Proprietary experiments
- Credentials or access details

## Quality Standard

Every public artifact should be:

1. Clear
2. Reusable
3. Evidence-aware
4. Free from unsupported claims
5. Useful without private context
