# Public Profile Guide

## Positioning

Full-Stack Marketing OS is an AI marketing system that combines marketing skills, frameworks, playbooks, templates, and evaluations into a reusable operating structure.

## Portfolio Description

Built an open-source AI marketing operating system for planning, auditing, and improving paid media, creative strategy, CRO, SEO, analytics, and reporting workflows.

## Principles

- Share systems, not private client information.
- Show methodology, not confidential account data.
- Use anonymized examples.
- Avoid claiming access to hidden platform algorithms.
