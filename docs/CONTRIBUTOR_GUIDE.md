# Contributor Guide

## Purpose

Contributors help improve the Marketing OS by adding structured knowledge, workflows, examples, and evaluations.

## Contribution Rules

1. Add evidence-based improvements.
2. Keep frameworks separated from tactics.
3. Document assumptions and limitations.
4. Prefer reusable systems over one-off advice.
5. Include examples when adding new capabilities.

## Adding New Content

A new capability should follow:

Problem → Research → Framework → Workflow → Template → Evaluation → Example

## Quality Standard

Every contribution should be practical, clear, and maintainable.
